# AboutMoney

Personal finance web app combining expense tracking and bill splitting.

**Features**
- Expense & income tracking with category colour codes
- Split expenses with friends — per-person Settle buttons
- Monthly donut chart with AI spending insights
- Group bills (Goa Trip, Flat, Office Lunch…)
- Budget tracker by category
- EMI calculator, Tax estimator, FD reminders, Subscription tracker

**Stack**: Single-file HTML/CSS/JS · localStorage · Zero dependencies

Live at: https://23bmiit016.github.io/aboutmoney
